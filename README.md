# millenaire_community_textures
Updated textures for Millenaire 9 by the community. All textures used with explicit permission or with following the relevant license. This resource pack is WIP and more textures will be added as they are contributed

Files inside this texture pack prefixed with `mct_` are *not* overrides (ie, they aren't in the original millenaire jar) but are *used by* overrides.
