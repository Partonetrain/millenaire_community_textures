# millenaire_community_textures
Updated textures for Millenaire 9 by the community. All textures included have been either used with explicit permission or by following the relevant license. This resource pack is WIP and more textures will be added as they are curated and contributed.

Files inside this texture pack prefixed with `mct_` are *not* overrides (ie, they aren't in the original millenaire jar) but are *used by* overrides.
